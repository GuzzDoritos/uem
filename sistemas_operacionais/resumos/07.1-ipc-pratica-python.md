# Aula 7.1: IPC na prática com Python

> Texto sem marcação vem dos slides. **[+]** indica complemento. Os códigos marcados como corrigidos diferem do slide.

## Formas de IPC
Processos são isolados: um não acessa a memória do outro. O SO oferece:

| Forma | Como | Sincronização |
|---|---|---|
| **Memória compartilhada** | Região mapeada no espaço de endereçamento de dois ou mais processos | Por conta dos processos |
| **Troca de mensagens** | Via núcleo | Embutida (receive bloqueia) |

- A região deve ser **criada** e **ligada** (anexada) ao processo.
- O SO gerencia regiões e processos; o **conteúdo** é responsabilidade dos processos.
- Não há sincronização automática: use, por exemplo, semáforos **também compartilhados** entre os processos.
- Ideia: A faz `x = compartilhada('comp'); x = 10` e B, ligado à mesma região, imprime `10`.

## Conversão para bytes
A escrita é de baixo nível (bytes), e em Python tudo é objeto: é preciso serializar.
```python
>>> x = 'ola mundo!'
>>> b = x.encode()          # str -> bytes (UTF-8 por padrão)
>>> b[2]                    # índice em bytes devolve int
97
>>> b.decode()[2]           # em str devolve caractere
'a'
```
> **[+]** Para números: `int.to_bytes` / `int.from_bytes`, ou o módulo `struct`.

## Opção 1: `multiprocessing.shared_memory`
`SharedMemory(name, create=False, size=0, track=True)`

| Parâmetro | Significado |
|---|---|
| `name` | Identificador da região |
| `create` | Criar a região (erro se já existir) |
| `size` | Tamanho em bytes |
| `track` | Se um rastreador de recursos limpará a memória (**[+]** existe a partir do Python 3.13) |

- Acesso pelo campo `buf`: leitura com `.tobytes()` ou `.tolist()`; escrita por **fatiamento com o tamanho exato** dos bytes.
```python
>>> m = SharedMemory(name='memcomp', create=True, size=20)
>>> m.buf[:10] = b'ola mundo!'
>>> m.buf.tobytes()
b'ola mundo!\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00'
```

### Escritor (corrigido)
```python
from multiprocessing.shared_memory import SharedMemory

x = SharedMemory(name='area_comp', create=True, size=30)
msg_b = input('> ').encode()[:30]
x.buf[:len(msg_b)] = msg_b          # slide usa len(msg)
input('pressione enter para encerrar...')
x.close()                           # desliga deste processo
x.unlink()                          # destrói a região
```
> ⚠️ No slide, `x.buf[:len(msg)] = msg_b` falha com acentos, pois `ç` ou `á` ocupam 2 bytes em UTF-8 e `len(msg)` conta caracteres.

### Leitor
```python
from multiprocessing.shared_memory import SharedMemory

x = SharedMemory(name='area_comp', track=False)
texto = x.buf.tobytes().rstrip(b'\x00').decode()   # [+] remove os zeros de sobra
print(f'string da memoria compartilhada: {texto}')
x.close()
```
Executar o escritor primeiro e, com ele parado no `input`, o leitor em outro terminal.

## Opção 2: biblioteca `posix_ipc`
> ⚠️ O slide diz que Python não tem nativamente semáforos ou locks. Tem (`threading.Lock/Semaphore` e `multiprocessing.Lock/Semaphore`). O que a biblioteca padrão não oferece é um **semáforo nomeado** que programas independentes abram pelo nome; para isso serve o `posix_ipc`.

### Instalação em ambiente virtual
```bash
python3 -m venv ./ambiente_virtual
source ./ambiente_virtual/bin/activate
pip3 install posix_ipc
```
> ⚠️ Nos exemplos do slide falta a palavra `venv` (`python3 -m /caminho` não funciona).

> **[+]** `posix_ipc` é para sistemas POSIX (Linux, macOS). No Windows, use o WSL.

### Classes principais
| Classe | Função |
|---|---|
| `SharedMemory` | Segmento de memória compartilhada |
| `Semaphore` | Semáforo compartilhado |
| `MessageQueue` | Fila de mensagens (troca de mensagens) |

Todos os objetos são identificados por **nome**, como arquivos (**[+]** começa com `/`).

### SharedMemory + mmap
- `posix_ipc.SharedMemory(name, flags=..., size=...)` apenas cria ou abre o segmento; flags no estilo da chamada `open` (`O_CREAT` etc.).
- O mapeamento é feito pelo módulo padrão `mmap`: `mmap.mmap(fileno, length, ...)`.
- Métodos: `seek(pos)`, `read()`, `write(bytes)`, `close()`.

> **[+]** Para abrir somente para leitura, use `read_only=True` no `posix_ipc.SharedMemory` e `access=mmap.ACCESS_READ` no `mmap`. No `posix_ipc`, a flag `O_RDONLY` sozinha não restringe o acesso.

**Escritor**
```python
import posix_ipc, mmap

shm = posix_ipc.SharedMemory('/shared_msg', flags=posix_ipc.O_CREAT, size=512)
mp = mmap.mmap(shm.fileno(), shm.size)
mp.seek(0)
mp.write(input('> ').encode())
input('pressione enter para encerrar...')
mp.close()
shm.close_fd()
shm.unlink()        # [+] ausente no slide; sem isso o segmento permanece no sistema
```

**Leitor** (no slide está rotulado como "escritor")
```python
import posix_ipc, mmap

shm = posix_ipc.SharedMemory('/shared_msg')
mp = mmap.mmap(shm.fileno(), shm.size)
mp.seek(0)
print(f"mensagem lida: {mp.read().rstrip(bytes(1)).decode()}")
mp.close()
shm.close_fd()
```

### Semaphore
`posix_ipc.Semaphore(name, flags=..., initial_value=...)`

| Método | Equivale a |
|---|---|
| `acquire()` | `down` |
| `release()` | `up` |

> **[+]** Exemplo sincronizado: o leitor espera o escritor.
> ```python
> # escritor.py
> import posix_ipc, mmap
> shm = posix_ipc.SharedMemory('/msg', flags=posix_ipc.O_CREAT, size=512)
> pronto = posix_ipc.Semaphore('/pronto', flags=posix_ipc.O_CREAT, initial_value=0)
> lido = posix_ipc.Semaphore('/lido', flags=posix_ipc.O_CREAT, initial_value=0)
> mp = mmap.mmap(shm.fileno(), shm.size)
> dados = input('> ').encode()[:511]
> mp.write(dados + bytes(1))
> pronto.release()      # up: há mensagem
> lido.acquire()        # down: espera a leitura
> mp.close(); shm.close_fd(); shm.unlink(); pronto.unlink(); lido.unlink()
>
> # leitor.py (inicie depois do escritor)
> import posix_ipc, mmap
> shm = posix_ipc.SharedMemory('/msg')
> pronto = posix_ipc.Semaphore('/pronto')
> lido = posix_ipc.Semaphore('/lido')
> mp = mmap.mmap(shm.fileno(), shm.size)
> pronto.acquire()
> print(mp.read().split(bytes(1))[0].decode())
> lido.release()
> mp.close(); shm.close_fd()
> ```
